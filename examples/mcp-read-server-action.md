# Ler uma Server Action pelo MCP OutSystems

Com o módulo aberto no Service Studio, inicie uma conversa e cole o prompt abaixo. Os nomes `BibliotecaDemo_CS` e `ConsultarDisponibilidadeLivro` são fictícios. Substitua-os pelos nomes do seu ambiente ao executar o teste.

```text
Leia somente a Server Action ConsultarDisponibilidadeLivro do módulo BibliotecaDemo_CS.
Use apenas as ferramentas de leitura anunciadas pelo MCP OutSystems, com os parâmetros declarados por elas. Se precisar da key do módulo, consulte-a primeiro pelo MCP. Não use o terminal.

Se faltar uma ferramenta necessária, pare e informe qual operação ficou bloqueada. Se uma chamada falhar, pare na primeira falha e informe a ferramenta, os argumentos e o erro retornado, ocultando credenciais e dados sensíveis.

Ao concluir a leitura, mostre o nome da ação e um detalhe do fluxo presente no retorno. Se o retorno não contiver o fluxo, informe essa limitação sem inferir o comportamento pelo nome da ação.
```
