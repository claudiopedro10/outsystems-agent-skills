# Como contribuir

Abra uma issue com a necessidade ou envie um pull request com uma melhoria concreta.

1. Descreva a tarefa que a skill deve atender e a plataforma.
2. Use uma pasta `skills/outsystems-nome/` com `SKILL.md`.
3. Escreva uma descrição que permita distinguir a skill das existentes.
4. Inclua um exemplo sintético e o resultado esperado.
5. Cite fontes oficiais para instruções específicas da plataforma ou agente.
6. Registre o que foi realmente verificado e o que permanece sem teste.
7. Atualize o catálogo e os links afetados.

Não envie exportações, capturas, logs ou dados de clientes sem autorização. Não inclua credenciais. Preserve a licença MIT e o aviso de projeto independente.

Revisão: clareza de escopo, correção por plataforma, ausência de suposições não declaradas, links válidos e instruções verificáveis.
